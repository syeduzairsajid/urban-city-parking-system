# Urban City Parking – Parking Management System

This project implements a Parking Management System for Urban City Parking
using Python and Object-Oriented Programming principles.

## Features
- Vehicle entry and exit tracking with timestamps
- Automatic fee calculation based on duration and vehicle type
- Monthly pass validation and management
- Single entry pass support
- Space allocation and availability tracking (300 spaces)
- Hour-by-hour pricing strategy:
  - Weekday peak / off-peak
  - Weekend pricing
- Use of Abstract Base Classes (ABC), inheritance, and polymorphism
